迁移校订

题目： ​

给你一个字符串数组，请你将 字母异位词 组合在一起。可以按任意顺序返回结果列表。

示例 1:输入: strs = ["eat", "tea", "tan", "ate", "nat", "bat"] 输出: [ ["bat"],["nat","tan"],["ate","eat","tea"] ] 解释：

  • 在 strs 中没有字符串可以通过重新排列来形成 "bat"。
  • 字符串 "nat" 和 "tan" 是字母异位词，因为它们可以重新排列以形成彼此。
  • 字符串 "ate" ，"eat" 和 "tea" 是字母异位词，因为它们可以重新排列以形成彼此。

示例 2:输入: strs = [""] 输出: [ [""] ]

示例 3:输入: strs = ["a"] 输出: [ ["a"] ]

哈希表分组解法 ​

核心思想：以「排序后的字符串」为哈希key，将字母组成相同的字符串分到同一组。

  • 互为异位词的字符串排序后结果完全相同，天然可作为分组标识

关键要点 ​

  1. 字典key = 排序后的字符串，value = 对应原字符串列表
  2. sorted(s)返回字符列表，需用''.join()转为字符串才能当key
  3. 遍历每个字符串，按key追加到对应列表
  4. 最终返回 list(d.values()) 得到分组结果
  5. 时间：$O(n \cdot k\log k)$（n为字符串数，k为字符串最大长度）；空间：$O(n \cdot k)$

代码 ​

python
class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        d = {}
        for s in strs:
            sorted_s = ''.join(sorted(s))
            if sorted_s not in d:
                d[sorted_s] = []
            d[sorted_s].append(s)
        return list(d.values())
