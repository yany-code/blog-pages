05 · 盛最多水的容器 ​

Python 题解以 Python 3.10+ 的力扣环境为背景；节点类型由题目提供。局部代码片段用于说明步骤。

迁移校订

  • 措辞校订：移动高边不能获得更大面积，但面积不一定严格变小。
  • 运行说明：独立运行时需补充 from typing import List；原笔记按题目环境展示。
题目： ​

给定一个长度为 n 的整数数组 height 。有 n 条垂线，第 i 条线的两个端点是 (i, 0) 和 (i, height[i]) 。 找出其中的两条线，使得它们与 x 轴共同构成的容器可以容纳最多的水。 返回容器可以储存的最大水量。 **说明：**你不能倾斜容器。

示例 1：

输入：[1,8,6,2,5,4,8,3,7] **输出：**49 **解释：**图中垂直线代表输入数组 [1,8,6,2,5,4,8,3,7]。在此情况下，容器能够容纳水（表示为蓝色部分）的最大值为 49。

示例 2：

**输入：**height = [1,1] **输出：**1

对撞双指针（贪心）解法 ​

核心思想：左右指针从数组两端向中间靠拢，每次计算当前容器面积，然后移动高度较矮的一侧指针。面积由「短板高度」和「两指针宽度」共同决定，只有移动矮指针才有可能获得更大的面积，移动较高一侧不会增大面积。

关键要点 ​

  1. 初始双指针：左指针slow在数组头部，右指针fast在数组尾部
  2. 面积公式：(右指针下标 - 左指针下标) × min(左高度, 右高度)
  3. 移动规则：哪边高度更小，就移动哪边的指针向中间靠拢
  4. 全程维护最大面积res，每次计算后更新最大值
  5. 时间复杂度：$O(n)$，仅一次遍历；空间复杂度：$O(1)$，常数额外空间

代码 ​

python
class Solution:
    def maxArea(self, height: List[int]) -> int:
        slow = 0
        fast = len(height) - 1
        res = 0
        while fast > slow:
            res = max(res, (fast - slow) * min(height[fast], height[slow]))
            if height[slow] < height[fast]:
                slow += 1
            else:
                fast -= 1
        return res
