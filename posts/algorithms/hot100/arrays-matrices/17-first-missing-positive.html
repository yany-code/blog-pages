17 · 缺失的第一个正数 ​

Python 题解以 Python 3.10+ 的力扣环境为背景；节点类型由题目提供。局部代码片段用于说明步骤。

迁移校订

  • 约束校订：恢复原笔记复制时丢失的指数，如 10^4、10^5、2^31；未修改示例数据。
  • 版本说明：建议使用 Python 3.10+，以支持笔记采用的类型注解写法。
题目: ​

给你一个未排序的整数数组 nums ，请你找出其中没有出现的最小的正整数。

请你实现时间复杂度为 O(n) 并且只使用常数级别额外空间的解决方案。

示例 1：

**输入：**nums = [1,2,0] **输出：**3 **解释：**范围 [1,2] 中的数字都在数组中。

示例 2：

**输入：**nums = [3,4,-1,1] **输出：**2 **解释：**1 在数组中，但 2 没有。

示例 3：

**输入：**nums = [7,8,9,11,12] **输出：**1 **解释：**最小的正数 1 没有出现。

提示：

  • 1 <= nums.length <= 10^5
  • -2^31 <= nums[i] <= 2^31 - 1

原地哈希 / 下标置换 ​

解题思路 ​

核心目标是让值 x 尽量放到下标 x - 1 的位置上。

因为数组长度为 n，真正有意义的答案只可能出现在：

[1, n + 1]

所以只需要处理区间 [1, n] 内的数。

遍历数组时：

  • 如果 nums[i] 在 [1, n] 范围内；
  • 并且它还没有放到正确的位置；
  • 就把它和 nums[nums[i] - 1] 交换。

一直交换，直到当前位置的数：

  • 超出 [1, n]
  • 或者已经处在正确位置
  • 或者目标位置已经有相同的数

这样处理完后，数组会尽量满足：

nums[i] = i + 1

最后再扫描一遍，找到第一个不满足的位置即可。

关键思想 ​

把数组本身当作哈希表使用：

值 x → 下标 x - 1

这样就不需要额外的哈希集合，实现 O(1) 额外空间。

算法流程 ​

  1. 遍历数组。
  2. 对当前元素不断执行交换：
    • 必须满足 1 <= nums[i] <= n
    • 并且 nums[i] != nums[nums[i] - 1]
  3. 交换后继续检查当前位置。
  4. 再次遍历数组：
    • 如果 nums[i] != i + 1
    • 那么 i + 1 就是缺失的最小正数。
  5. 如果全部位置都正确，返回 n + 1。

复杂度分析 ​

  • 时间复杂度：O(n)
    • 虽然存在 while，但每个合法数字最多被交换到正确位置一次。
  • 空间复杂度：O(1)

Python代码 ​

python
class Solution:
    def firstMissingPositive(self, nums: list[int]) -> int:
        n = len(nums)

        for i in range(n):

            while 1 <= nums[i] <= n and nums[nums[i] - 1] != nums[i]:
                j = nums[i] - 1
                nums[i], nums[j] = nums[j], nums[i]

        for i in range(n):
            if nums[i] != i + 1:
                return i + 1

        return n + 1

易错点 ​

  • 值 x 对应的位置是 x - 1，因为数组下标从 0 开始。
  • 一定要用 while，因为交换过来的新值可能还需要继续交换。
  • 必须判断：

nums[nums[i] - 1] != nums[i]

否则遇到重复元素时可能死循环。

  • 小于等于 0 或大于 n 的数不需要处理。

总结 ​

这类题的核心套路是：

值映射到下标 → 原地交换归位 → 扫描第一个不匹配的位置

本质上就是利用数组自身实现哈希表。
