15 · 轮转数组 ​

Python 题解以 Python 3.10+ 的力扣环境为背景；节点类型由题目提供。局部代码片段用于说明步骤。

题目: ​

给定一个整数数组 nums，将数组中的元素向右轮转 k 个位置，其中 k 是非负数。

示例 1:

输入: nums = [1,2,3,4,5,6,7], k = 3 输出: [5,6,7,1,2,3,4]解释: 向右轮转 1 步: [7,1,2,3,4,5,6] 向右轮转 2 步: [6,7,1,2,3,4,5] 向右轮转 3 步: [5,6,7,1,2,3,4]

示例 2:

**输入：**nums = [-1,-100,3,99], k = 2 输出：[3,99,-1,-100] 解释: 向右轮转 1 步: [99,-1,-100,3] 向右轮转 2 步: [3,99,-1,-100]

提示：

  • 1 <= nums.length <= 10^5
  • -2^31 <= nums[i] <= 2^31 - 1
  • 0 <= k <= 10^5

数组翻转 ​

解题思路 ​

使用三次反转法实现数组右旋。

假设数组长度为 n，向右移动 k 位：

  1. 先将整个数组反转。
  2. 再反转前 k 个元素。
  3. 最后反转剩余 n-k 个元素。

例如：

[1,2,3,4,5,6,7], k=3

整体反转：
[7,6,5,4,3,2,1]

反转前3个：
[5,6,7,4,3,2,1]

反转剩余：
[5,6,7,1,2,3,4]

得到最终结果。

关键思想 ​

右旋 k 位，本质是把数组分成两部分：

A B

旋转后变成：

B A

通过三次反转：

A B
↓ 整体反转
B^ A^
↓ 分别反转两个分段
B A

实现原地交换。

算法流程 ​

  1. 计算有效移动次数：
k = k % n

避免 k > n 的情况。

  1. 定义反转函数：
    • 双指针交换元素。
  2. 三次调用反转：
    • 反转整个数组。
    • 反转前 k 个元素。
    • 反转剩余元素。

复杂度分析 ​

  • 时间复杂度：O(n)
    • 每个元素最多被反转几次。
  • 空间复杂度：O(1)
    • 原地修改数组。

Python代码 ​

python
class Solution:
    def rotate(self, nums: list[int], k: int) -> None:

        def reverse(i: int, j: int) -> None:
            while i < j:
                nums[i], nums[j] = nums[j], nums[i]
                i += 1
                j -= 1

        n = len(nums)
        k %= n

        reverse(0, n - 1)
        reverse(0, k - 1)
        reverse(k, n - 1)

易错点 ​

  • k 可能大于数组长度，需要先取模。
  • 注意题目要求原地修改，不需要返回数组。
  • k=0 时反转区间需要正确处理。
  • 本实现采用先整体反转、再分别反转两个分段的顺序。

总结 ​

数组旋转问题可以使用：

整体反转 → 前 k 个反转 → 后面反转

实现 O(n) 时间和 O(1) 空间的原地操作。
