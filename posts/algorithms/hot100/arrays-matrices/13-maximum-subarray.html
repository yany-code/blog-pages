题目: ​

你一个整数数组 nums ，请你找出一个具有最大和的连续子数组（子数组最少包含一个元素），返回其最大和。

子数组是数组中的一个连续部分。

示例 1：

**输入：**nums = [-2,1,-3,4,-1,2,1,-5,4] **输出：**6 **解释：**连续子数组 [4,-1,2,1] 的和最大，为 6 。

示例 2：

**输入：**nums = [1] **输出：**1

示例 3：

**输入：**nums = [5,4,-1,7,8] **输出：**23

提示：

  • 1 <= nums.length <= 10^5
  • -10^4 <= nums[i] <= 10^4

前缀和 + 最小前缀和 ​

解题思路 ​

用前缀和把“连续子数组的和”转化成两个前缀和之差。

设当前前缀和为：

pre_sum

如果某段子数组从位置 l 到 r，那么它的和可以写成：

pre_sum[r] - pre_sum[l - 1]

因此，对于当前右端点来说，想让子数组和尽可能大，就应该减去之前出现过的最小前缀和。

所以遍历数组时维护两个量：

  • pre_sum：当前前缀和
  • min_pre_sum：此前出现过的最小前缀和

每次更新答案：

ans = max(ans, pre_sum - min_pre_sum)

然后再更新最小前缀和。

关键思想 ​

本质是：

最大子数组和 = 当前前缀和 - 前面最小的前缀和

所以问题变成了一边遍历，一边维护“历史最小值”。

算法流程 ​

  1. 初始化当前前缀和为 0
  2. 初始化最小前缀和为 0
  3. 遍历数组：
    • 累加当前元素
    • 用 pre_sum - min_pre_sum 更新答案
    • 更新最小前缀和
  4. 返回最大值

复杂度分析 ​

  • 时间复杂度：O(n)
  • 空间复杂度：O(1)

Python代码 ​

python
class Solution:
    def maxSubArray(self, nums: List[int]) -> int:
        ans = -inf
        min_pre_sum = pre_sum = 0

        for x in nums:
            pre_sum += x

            ans = max(ans, pre_sum - min_pre_sum)

            min_pre_sum = min(min_pre_sum, pre_sum)

        return ans

易错点 ​

  • min_pre_sum 初始值要设为 0
  • 要先更新答案，再更新 min_pre_sum
  • ans 不能初始化为 0，因为数组可能全是负数

总结 ​

连续子数组求最大和时，可以把它转成前缀和问题：

当前前缀和 - 历史最小前缀和
