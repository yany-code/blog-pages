36 · 二叉树的中序遍历 ​

Python 题解以 Python 3.10+ 的力扣环境为背景；节点类型由题目提供。局部代码片段用于说明步骤。

迁移校订

  • 代码校订：将 Morris 前序、后序代码缩进中的不换行空格替换为普通空格，消除复制运行时的 SyntaxError。
  • 运行说明：独立运行时需补充 from typing import List, Optional；原笔记按题目环境展示。
  • 版本说明：建议使用 Python 3.10+，以支持笔记采用的类型注解写法。
  • 节点说明：TreeNode 为题目提供的节点类型，本地运行时需提供相同结构；不应从第三方库猜测导入。
题目: ​

给定一个二叉树的根节点 root ，返回 它的 中序 遍历 。

示例 1：

**输入：**root = [1,null,2,3] 输出：[1,3,2]

示例 2：

**输入：**root = [] 输出：[]

示例 3：

**输入：**root = [1] 输出：[1]

提示：

  • 树中节点数目在范围 [0, 100] 内
  • -100 <= Node.val <= 100

递归 DFS（中序遍历） ​

解题思路 ​

二叉树的中序遍历顺序是：

左子树 → 根节点 → 右子树

使用递归 DFS 遍历二叉树。每访问一个节点，按照上述顺序执行三个步骤：

  1. 递归遍历左子树。
  2. 将当前节点的值加入结果数组 ans。
  3. 递归遍历右子树。

当节点为空（node is None）时，说明递归到达空子树，直接返回。

核心代码 ​

python
class Solution:
    def inorderTraversal(self, root: Optional[TreeNode]) -> list[int]:
        ans = []

        def dfs(node):
            if node is None:
                return

            dfs(node.left)
            ans.append(node.val)
            dfs(node.right)

        dfs(root)
        return ans

执行过程 ​

以二叉树为例：

text
    1
     \
      2
     /
    3

对应输入：

python
root = [1, None, 2, 3]

按照中序遍历的顺序执行：

  1. 从根节点 1 开始，先递归访问左子树。左子树为空，返回。
  2. 访问节点 1，将 1 加入 ans。
  3. 递归访问节点 1 的右子树，即节点 2。
  4. 节点 2 的左子树是节点 3，继续递归。
  5. 节点 3 没有左子树，将 3 加入 ans。
  6. 节点 3 没有右子树，返回节点 2。
  7. 将 2 加入 ans，最后返回结果。

最终结果：

python
[1, 3, 2]

关键知识点 ​

1. 为什么先递归左子树？ ​

中序遍历规定必须先访问左子树，再访问根节点，最后访问右子树。

python
dfs(node.left)
ans.append(node.val)
dfs(node.right)

三行代码的顺序决定了遍历方式。

  • 中序遍历：左 → 根 → 右
  • 前序遍历：根 → 左 → 右
  • 后序遍历：左 → 右 → 根

三种遍历的区别主要在于处理根节点的时机。

2. 为什么需要递归终止条件？ ​

python
if node is None:
    return

当节点为空时，不能继续访问 node.left 或 node.right，因此必须结束当前递归。

这个条件同时处理了空树的情况：如果 root is None，最终返回空数组 []。

3. 为什么 dfs 不需要返回值？ ​

python
def dfs(node):

dfs 的任务是遍历节点，并把节点值添加到外部的 ans 数组中。

因此，递归函数只需要执行操作，不需要返回遍历结果。

python
dfs(root)
return ans

这里的 dfs(root) 负责填充数组，return ans 才是题目要求的最终返回值。

复杂度分析 ​

设二叉树共有 (n) 个节点，树的高度为 (h)。

  • 时间复杂度： (O(n))

    每个节点恰好访问一次。

  • 空间复杂度： (O(h)) 递归调用栈。

    最坏情况下，二叉树退化成链表，递归栈空间为 (O(n))；如果树较为平衡，则递归栈空间为 (O(\log n))。

    此外，结果数组需要 (O(n)) 空间。如果将返回结果所占空间也计算在内，总空间复杂度为 (O(n))。

方法对比 ​

方法时间复杂度辅助空间特点
递归 DFS(O(n))(O(h))代码简洁，容易理解
迭代 + 栈(O(n))(O(h))显式维护遍历过程，不依赖递归
Morris 遍历(O(n))(O(1))利用临时线索连接节点，不使用递归栈

总结 ​

递归中序遍历的核心是：

递归左子树 → 访问根节点 → 递归右子树。

记住递归终止条件，并明确根节点应该在什么时候加入结果数组，就能写出二叉树的三种深度优先遍历。

Morris 遍历（中序遍历） ​

解题思路 ​

二叉树的中序遍历顺序是：

左子树 → 根节点 → 右子树

递归 DFS 需要递归调用栈，迭代法需要显式维护栈，而 Morris 遍历可以在 (O(1)) 额外空间 下完成中序遍历。

核心思想是：利用当前节点左子树中最右侧的节点，暂时建立一条指向当前节点的线索。

对于当前节点 root，分两种情况处理：

情况一：当前节点没有左子树 ​

python
if root.left is None:
    ans.append(root.val)
    root = root.right

因为没有左子树，可以直接访问当前节点，然后转向右子树。

情况二：当前节点存在左子树 ​

找到当前节点左子树中最右侧的节点 pre：

python
pre = root.left
while pre.right and pre.right is not root:
    pre = pre.right

这里的 pre 是当前节点在左子树中的中序前驱。

接下来分两种情况：

  • 情况 A：pre.right is None

    说明还没有建立线索，将 pre.right 指向当前节点 root，然后进入左子树继续遍历。

  • 情况 B：pre.right is root

    说明之前已经建立过线索，当前左子树已经遍历完成。此时需要删除线索，将当前节点加入结果数组，然后转向右子树。

核心代码 ​

python
class Solution:
    def inorderTraversal(self, root: Optional[TreeNode]) -> list[int]:
        ans = []

        while root:
            if root.left:
                pre = root.left

                while pre.right and pre.right is not root:
                    pre = pre.right

                if pre.right is None:
                    pre.right = root
                    root = root.left
                    continue

                pre.right = None

            ans.append(root.val)
            root = root.right

        return ans

执行过程 ​

以如下二叉树为例：

text
1
 \
  2
 /
3

输入：

python
root = [1, None, 2, 3]

第一步：处理节点 1 ​

节点 1 存在左子树吗？

不存在，因此直接访问节点 1：

python
ans = [1]

然后移动到 root.right，即节点 2。

第二步：处理节点 2 ​

节点 2 存在左子树，左子树为节点 3。

从 root.left 开始寻找中序前驱：

python
pre = root.left

此时 pre 指向节点 3。

由于 pre.right is None，建立临时线索：

python
pre.right = root

此时节点 3 的右指针暂时指向节点 2。

然后进入左子树：

python
root = root.left

现在 root 指向节点 3。

第三步：处理节点 3 ​

节点 3 没有左子树，直接访问：

python
ans = [1, 3]

随后执行：

python
root = root.right

由于之前建立了临时线索，root 会回到节点 2。

第四步：恢复线索并访问节点 2 ​

再次处理节点 2，找到它的中序前驱节点 3。

这次发现：

python
pre.right is root

说明左子树已经遍历完成，于是删除临时线索：

python
pre.right = None

然后访问节点 2：

python
ans = [1, 3, 2]

最后转向右子树，遍历结束。

最终结果：

python
[1, 3, 2]

关键知识点 ​

1. 为什么要判断 pre.right is not root？ ​

python
while pre.right and pre.right is not root:
    pre = pre.right

寻找中序前驱时，需要找到左子树中最右侧的节点。

但 Morris 遍历可能已经把这个节点的右指针临时指向当前节点。

如果不检查 pre.right is not root，就可能沿着临时线索返回当前节点，导致寻找过程无法正确结束。

2. 为什么建立线索后要 continue？ ​

python
pre.right = root
root = root.left
continue

此时左子树还没有遍历完成，不能立即访问当前节点。

因此需要进入左子树，并跳过本轮后面的访问操作。

等之后通过临时线索返回当前节点时，再访问它。

3. 为什么最后要恢复 pre.right = None？ ​

python
pre.right = None

临时线索只是为了帮助遍历返回当前节点，不属于原始二叉树结构。

左子树遍历完成后，必须删除这条线索，恢复原来的树结构。

Morris 遍历会暂时修改树的指针，但遍历结束后会恢复这些修改。

4. Morris 遍历为什么不需要栈？ ​

普通递归需要调用栈记录返回位置，迭代法则使用显式栈保存待访问节点。

Morris 遍历通过临时修改节点的右指针，建立从左子树返回当前节点的通路，因此不需要额外的栈。

复杂度分析 ​

设二叉树共有 (n) 个节点。

  • 时间复杂度：(O(n))

    虽然需要寻找中序前驱，但整体遍历过程中，每条临时线索最多建立和删除一次，因此总时间复杂度为 (O(n))。

  • 辅助空间复杂度：(O(1))

    只使用有限个指针变量，没有使用递归栈、显式栈或额外的数据结构存储遍历过程。

    如果把返回结果数组 ans 也计算在内，总空间复杂度为 (O(n))。

方法对比 ​

方法时间复杂度辅助空间复杂度特点
递归 DFS(O(n))(O(h))代码简洁，容易理解
迭代 + 栈(O(n))(O(h))手动维护遍历顺序
Morris 遍历(O(n))(O(1))利用临时线索实现遍历

其中，(h) 表示二叉树的高度。

总结 ​

Morris 中序遍历的核心是：

  1. 当前节点没有左子树时，直接访问当前节点并向右移动。
  2. 当前节点存在左子树时，找到左子树的中序前驱。
  3. 如果前驱没有右指针，就建立临时线索并进入左子树。
  4. 如果前驱的右指针已经指向当前节点，就删除线索、访问当前节点，再向右移动。

记忆重点：第一次遇到前驱时建立线索，第二次返回时删除线索并访问当前节点。

Morris遍历（前序遍历、后序遍历）: ​

前序遍历:

python
class Solution:

    def preorderTraversal(self, root: Optional[TreeNode]) -> List[int]:
        ans = []

        while root:
            pre = root.left

            if pre:
                while pre.right and pre.right is not root:
                    pre = pre.right
                if pre.right is None:
                    ans.append(root.val)
                    pre.right = root
                    root = root.left
                    continue
                pre.right = None
            else:
                ans.append(root.val)
            root = root.right

        return ans

后序遍历:

python
class Solution:

    def postorderTraversal(self, root: Optional[TreeNode]) -> List[int]:
        ans = []

        while root:
            pre = root.right

            if pre:
                while pre.left and pre.left is not root:
                    pre = pre.left
                if pre.left is None:
                    ans.append(root.val)
                    pre.left = root
                    root = root.right
                    continue
                pre.left = None
            else:
                ans.append(root.val)
            root = root.left

        ans.reverse()
        return ans
