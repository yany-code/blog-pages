25 · 环形链表 ​

Python 题解以 Python 3.10+ 的力扣环境为背景；节点类型由题目提供。局部代码片段用于说明步骤。

迁移校订

  • 约束校订：恢复原笔记复制时丢失的指数，如 10^4、10^5、2^31；未修改示例数据。
  • 版本说明：建议使用 Python 3.10+，以支持笔记采用的类型注解写法。
  • 节点说明：ListNode 为题目提供的节点类型，本地运行时需提供相同结构；不应从第三方库猜测导入。
题目: ​

给你一个链表的头节点 head ，判断链表中是否有环。

如果链表中有某个节点，可以通过连续跟踪 next 指针再次到达，则链表中存在环。 为了表示给定链表中的环，评测系统内部使用整数 pos 来表示链表尾连接到链表中的位置（索引从 0 开始）。注意：pos 不作为参数进行传递 。仅仅是为了标识链表的实际情况。

如果链表中存在环 ，则返回 true 。 否则，返回 false 。

示例 1：

**输入：**head = [3,2,0,-4], pos = 1 **输出：**true **解释：**链表中有一个环，其尾部连接到第二个节点。

示例 2：

**输入：**head = [1,2], pos = 0 **输出：**true **解释：**链表中有一个环，其尾部连接到第一个节点。

示例 3：

**输入：**head = [1], pos = -1 **输出：**false **解释：**链表中没有环。

提示：

  • 链表中节点的数目范围是 [0, 10^4]
  • -10^5 <= Node.val <= 10^5
  • pos 为 -1 或者链表中的一个 有效索引 。

快慢指针判断环形链表 ​

解题思路 ​

使用快慢指针判断链表是否存在环。

定义两个指针：

  • slow：每次移动一步。
  • fast：每次移动两步。

如果链表存在环：

  • 快指针进入环后，由于速度比慢指针快，最终一定会追上慢指针。
  • 即：
python
fast == slow

如果不存在环：

  • 快指针会先走到链表末尾 None。

关键思想 ​

利用两个指针速度差判断环：

slow:  每次 +1

fast:  每次 +2

在环形区域中：

  • 快指针相对于慢指针每次靠近一步。
  • 因此一定会相遇。

类似两个人在环形跑道上跑步，速度更快的人最终会追上慢的人。

算法流程 ​

  1. 初始化：
python
slow = fast = head
  1. 循环移动：
  • 慢指针走一步。
  • 快指针走两步。
  1. 每次移动后判断：
python
slow == fast

如果相等，说明存在环。

  1. 如果快指针无法继续移动，说明无环。

复杂度分析 ​

  • 时间复杂度：O(n)
    • 最多遍历链表有限次数。
  • 空间复杂度：O(1)
    • 只使用两个指针。

Python代码 ​

python
class Solution:
    def hasCycle(self, head: ListNode | None) -> bool:

        slow = fast = head

        while fast and fast.next:

            slow = slow.next
            fast = fast.next.next

            if slow == fast:
                return True

        return False

易错点 ​

  • 循环条件必须判断：
python
fast and fast.next

避免访问空节点。

  • 判断的是：
python
slow == fast

而不是：

python
slow.val == fast.val

因为不同节点可能拥有相同的值。

  • 快指针必须一次走两步，否则无法产生速度差。

总结 ​

判断链表是否有环的经典方法：

快慢指针

快指针每次走两步，慢指针每次走一步：

  • 有环 → 两者最终相遇
  • 无环 → 快指针到达末尾
