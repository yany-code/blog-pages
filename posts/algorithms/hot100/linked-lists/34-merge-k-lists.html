34 · 合并 K 个升序链表 ​

Python 题解以 Python 3.10+ 的力扣环境为背景；节点类型由题目提供。局部代码片段用于说明步骤。

迁移校订

  • 复杂度补充：设 K 为输入链表数量、N 为节点总数。堆方法还需扫描 K 个头节点，时间为 O(K+N log(K+1))；当前分治实现使用 Python 切片，需计入 O(K log(K+1)) 的引用复制成本，辅助空间为 O(K)。
  • 排版说明：示例中的 lists = [[]] 是空链表数组，不是 Obsidian 双链。
  • 运行说明：独立运行时需补充 from typing import Optional；原笔记按题目环境展示。
  • 版本说明：建议使用 Python 3.10+，以支持笔记采用的类型注解写法。
  • 节点说明：ListNode 为题目提供的节点类型，本地运行时需提供相同结构；不应从第三方库猜测导入。
题目: ​

给你一个链表数组，每个链表都已经按升序排列。

请你将所有链表合并到一个升序链表中，返回合并后的链表。

示例 1：

**输入：**lists = [1,4,5],[1,3,4],[2,6] 输出：[1,1,2,3,4,4,5,6] **解释：**链表数组如下： [ 1->4->5, 1->3->4, 2->6 ] 将它们合并到一个有序链表中得到。 1->1->2->3->4->4->5->6

示例 2：

**输入：**lists = [] 输出：[]

示例 3：

**输入：**lists = [[]] 输出：[]

提示：

  • k == lists.length
  • 0 <= k <= 10^4
  • 0 <= lists[i].length <= 500
  • -10^4 <= lists[i][j] <= 10^4
  • lists[i] 按 升序 排列
  • lists[i].length 的总和不超过 10^4

最小堆（优先队列）多路归并 ​

解题思路 ​

利用最小堆维护每条有序链表当前未处理的头节点，每次取出全局最小节点，将其加入结果链表，再把该节点的下一个节点放入堆中。

  1. 初始化堆：将所有非空链表的头节点放入最小堆。
  2. 取出最小节点：弹出堆顶，得到当前所有候选节点中的最小值。
  3. 连接结果链表：将该节点接到结果链表末尾。
  4. 补充节点：如果该节点还有后继节点，将其加入堆中。
  5. 重复操作：直到堆为空，返回结果链表。

关键思想 ​

1. 为什么只放每条链表的头节点？ ​

因为每条链表本身已经有序，后面的节点一定不小于当前节点。

例如：

text
链表1：1 → 4 → 5
链表2：1 → 3 → 4
链表3：2 → 6

初始候选节点：1、1、2

每次取出最小节点后，只需补入该节点所在链表的下一个节点，就能始终从所有候选节点中选出全局最小值。

2. 如何让最小堆比较链表节点？ ​

heapq 默认通过 < 比较元素，因此需要定义 ListNode 的比较方法：

python
ListNode.__lt__ = lambda a, b: a.val < b.val

这样就能根据节点的 val 属性维护最小堆。

3. 为什么使用虚拟头节点？ ​

python
cur = dummy = ListNode()
  • dummy：固定结果链表的起点。
  • cur：指向结果链表的末尾，方便连接新节点。

最终返回 dummy.next，跳过虚拟头节点。

复杂度分析 ​

设所有链表的节点总数为 N，链表数量为 k。

  • 时间复杂度： O(N log k)。每个节点最多入堆、出堆各一次，每次堆操作需要 O(log k)。
  • 空间复杂度： O(k)。最小堆最多保存 k 个节点，不计输出链表及输入数据。

Python 代码 ​

python
from heapq import heapify, heappop, heappush

ListNode.__lt__ = lambda a, b: a.val < b.val


class Solution:
    def mergeKLists(self, lists: list[ListNode | None]) -> ListNode | None:
        cur = dummy = ListNode()
        h = [head for head in lists if head]
        heapify(h)

        while h:
            node = heappop(h)

            if node.next:
                heappush(h, node.next)

            cur.next = node
            cur = cur.next

        return dummy.next

总结 ​

最小堆多路归并：每条有序链表只保留一个候选节点，每次取出全局最小值，再补入该链表的下一个节点。

核心操作：heapify 初始化堆、heappop 取最小值、heappush 补入后继节点。

分治 + 两两归并（合并 K 个升序链表） ​

解题思路 ​

利用分治思想，将 K 个有序链表不断分成两组，分别合并，最后得到一个完整的有序链表。

核心是将「合并 K 个链表」的问题转化为多个「合并两个有序链表」的问题。

整个过程分为两个步骤：

  1. 分：将链表数组 lists 从中间拆成左右两部分，递归合并每一部分。
  2. 合：将左右两部分得到的有序链表，使用双指针归并成一个有序链表。

关键思想 ​

1. 递归拆分链表数组 ​

设 m = len(lists)，表示当前需要合并的链表数量。

python
m = len(lists)

if m == 0:
    return None

if m == 1:
    return lists[0]

left = self.mergeKLists(lists[:m // 2])
right = self.mergeKLists(lists[m // 2:])

return self.mergeTwoLists(left, right)

递归终止条件：

  • m == 0：没有链表，返回 None。
  • m == 1：只有一个链表，它本身就是有序的，直接返回。

当链表数量大于 1 时，将其从中间拆分。

例如，合并 4 个链表：

text
        L1  L2  L3  L4
           /       \
        L1  L2     L3  L4
         / \        / \
        L1  L2     L3  L4

拆分到每组只剩一个链表后，再从底向上逐层合并。

2. 两两归并 ​

使用虚拟头节点 dummy 和指针 cur 合并两个有序链表。

python
cur = dummy = ListNode()

while list1 and list2:
    if list1.val < list2.val:
        cur.next = list1
        list1 = list1.next
    else:
        cur.next = list2
        list2 = list2.next

    cur = cur.next

cur.next = list1 if list1 else list2

return dummy.next

每次比较两个链表当前节点的值：

  • 哪个值更小，就将哪个节点接到结果链表末尾。
  • 对应链表的指针向后移动。
  • 当其中一个链表遍历完毕，将另一个链表剩余部分直接接上。

因为两个链表本身有序，所以合并后的链表仍然有序。

3. 完整执行过程 ​

假设输入：

text
L1：1 → 4 → 5
L2：1 → 3 → 4
L3：2 → 6

第一步：拆分链表数组。

text
左侧：L1、L2
右侧：L3

第二步：分别合并左右两部分。

text
merge(L1, L2)：

1 → 1 → 3 → 4 → 4 → 5

右侧：

2 → 6

第三步：合并左右两部分的结果。

text
1 → 1 → 2 → 3 → 4 → 4 → 5 → 6

最终返回合并后的有序链表。

复杂度分析 ​

设 K 为链表数量，N 为所有链表的节点总数。

  • 时间复杂度： O(N log K)

    每一层合并所有链表的总成本为 O(N)，而链表数组每次拆分为两半，递归深度为 O(log K)。

  • 空间复杂度： O(K)（当前代码使用切片拆分数组）。

    递归深度为 O(log K)，但 lists[:m // 2] 等切片会创建新的列表，因此实际辅助空间还包括切片产生的引用列表，总体为 O(K)。

Python 代码 ​

python
class Solution:

    # 合并两个有序链表
    def mergeTwoLists(
        self,
        list1: Optional[ListNode],
        list2: Optional[ListNode]
    ) -> Optional[ListNode]:

        cur = dummy = ListNode()

        while list1 and list2:
            if list1.val < list2.val:
                cur.next = list1
                list1 = list1.next
            else:
                cur.next = list2
                list2 = list2.next

            cur = cur.next

        # 接上剩余节点
        cur.next = list1 if list1 else list2

        return dummy.next

    # 分治合并 K 个有序链表
    def mergeKLists(
        self,
        lists: list[Optional[ListNode]]
    ) -> Optional[ListNode]:

        m = len(lists)

        # 递归终止条件
        if m == 0:
            return None

        if m == 1:
            return lists[0]

        # 分：拆分成左右两组
        left = self.mergeKLists(lists[:m // 2])
        right = self.mergeKLists(lists[m // 2:])

        # 合：合并两个有序链表
        return self.mergeTwoLists(left, right)

易错点 ​

  1. 递归终止条件不能遗漏。

    m == 0 返回 None，m == 1 直接返回唯一的链表，否则递归无法正常结束。

  2. 中间拆分使用整数除法。

    m // 2 可以保证拆分位置是整数。例如，3 个链表会被拆成 1 个和 2 个。

  3. 合并两个链表时必须移动指针。

    连接节点后，需要更新对应的链表指针以及 cur，否则可能造成重复连接或死循环。

  4. 不要忘记连接剩余节点。

    当其中一个链表为空时，另一个链表剩余部分已经有序，可以直接连接。

  5. 注意区分两种分治。

    本题拆分的是链表数组 lists，而 mergeTwoLists 合并的是两个链表。两者承担不同的任务。

总结 ​

分治 + 两两归并的核心流程：

拆分链表数组 → 递归合并左右两组 → 合并两个有序链表。

时间复杂度为 O(N log K)，适合合并大量有序链表。

与最小堆方法相比：

  • 分治归并： 不需要维护堆，依靠递归逐层合并。
  • 最小堆： 每次从 K 个候选节点中取出最小值，依靠优先队列维护顺序。

两种方法的时间复杂度都是 O(N log K)，但实现思路不同。
