33 · 排序链表 ​

Python 题解以 Python 3.10+ 的力扣环境为背景；节点类型由题目提供。局部代码片段用于说明步骤。

题目: ​

给你链表的头结点 head ，请将其按 升序 排列并返回 排序后的链表 。

示例 1：

**输入：**head = [4,2,1,3] 输出：[1,2,3,4]

示例 2：

**输入：**head = [-1,5,3,4,0] 输出：[-1,0,3,4,5]

示例 3：

**输入：**head = [] 输出：[]

提示：

  • 链表中节点的数目在范围 [0, 5 * 10^4] 内
  • -10^5 <= Node.val <= 10^5

归并排序 + 快慢指针拆分链表 ​

解题思路 ​

使用**归并排序（分治思想）**对链表进行排序。

归并排序的核心是：

先将链表不断拆分成两半，再将两个有序链表合并。

整个过程分为三个步骤：

  1. 拆分链表：利用快慢指针找到链表中点，将链表断成两部分。
  2. 递归排序：分别对左右两部分进行归并排序。
  3. 合并链表：利用双指针，将两个有序链表合并成一个有序链表。

关键思想 ​

1. 快慢指针寻找中点 ​

定义两个指针：

  • slow：每次走一步。
  • fast：每次走两步。
  • pre：记录 slow 的前一个节点，用来断开链表。
python
while fast and fast.next:
    pre = slow
    slow = slow.next
    fast = fast.next.next

pre.next = None

例如：

text
4 → 2 → 1 → 3

拆分：

4 → 2       1 → 3

注意：必须断开链表，否则递归时可能重复处理同一段链表。

2. 递归分治 ​

将链表不断拆分：

text
      4 → 2 → 1 → 3
          /     \
       4 → 2   1 → 3
       /   \    /   \
      4     2  1     3

递归终止条件：

python
if head is None or head.next is None:
    return head

当链表为空或只有一个节点时，本身就是有序的。

3. 合并两个有序链表 ​

使用虚拟头节点 dummy 和指针 cur。

每次比较两个链表的头节点：

  • 哪个值更小，就把哪个节点接到结果链表后面。
  • 对应链表指针向后移动。
  • 最后连接剩余的节点。
python
cur.next = list1 if list1 else list2

这一过程与归并排序中的合并操作完全相同。

算法流程 ​

  1. 判断链表是否为空或只有一个节点。
  2. 使用快慢指针找到中点，断开链表。
  3. 递归排序左半部分。
  4. 递归排序右半部分。
  5. 合并两个有序链表。
  6. 返回合并后的头节点。

复杂度分析 ​

  • 时间复杂度：O(n log n)
    • 每层递归合并需要 O(n)。
    • 链表每次拆成两半，递归深度为 O(log n)。
  • 空间复杂度：O(log n)
    • 归并操作只使用常数个指针。
    • 额外空间主要来自递归调用栈。

Python代码 ​

python
class Solution:

    # 快慢指针拆分链表
    def middleNode(self, head: Optional[ListNode]) -> Optional[ListNode]:
        slow = fast = head

        while fast and fast.next:
            pre = slow
            slow = slow.next
            fast = fast.next.next

        pre.next = None
        return slow

    # 合并两个有序链表
    def mergeTwoLists(
        self,
        list1: Optional[ListNode],
        list2: Optional[ListNode]
    ) -> Optional[ListNode]:

        cur = dummy = ListNode()

        while list1 and list2:
            if list1.val <= list2.val:
                cur.next = list1
                list1 = list1.next
            else:
                cur.next = list2
                list2 = list2.next

            cur = cur.next

        cur.next = list1 if list1 else list2

        return dummy.next

    # 归并排序
    def sortList(self, head: Optional[ListNode]) -> Optional[ListNode]:

        if head is None or head.next is None:
            return head

        # 拆分链表
        head2 = self.middleNode(head)

        # 递归排序左右两部分
        head = self.sortList(head)
        head2 = self.sortList(head2)

        # 合并有序链表
        return self.mergeTwoLists(head, head2)

易错点 ​

  • 找到中点后必须断开链表：
python
pre.next = None

否则递归无法正确缩小问题规模。

  • 拆分时要记录 slow 的前驱节点 pre，因为单链表无法直接访问前一个节点。
  • 递归终止条件必须处理空链表和单节点链表。
  • 合并时要将剩余节点连接到结果链表：
python
cur.next = list1 if list1 else list2
  • 链表归并排序不需要像数组归并排序那样创建临时数组，可以直接通过修改 next 指针合并。

总结 ​

链表归并排序的经典套路：

快慢指针找中点 → 断开链表 → 递归排序左右两半 → 合并有序链表

核心是分治思想：

  • 分：不断将链表拆成两半。
  • 治：递归排序每一部分。
  • 合：将两个有序链表合并。

最终实现 O(n log n) 时间复杂度，递归栈空间为 O(log n)。
