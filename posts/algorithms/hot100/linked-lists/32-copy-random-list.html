32 · 随机链表的复制 ​

Python 题解以 Python 3.10+ 的力扣环境为背景；节点类型由题目提供。局部代码片段用于说明步骤。

迁移校订

  • 排版校订：删除两种复制方法之间及文末的孤立围栏，恢复第二种方法的正文。
  • 代码校订：穿插复制第三阶段改为同时拆出新链表、恢复原链表；原写法会返回 None 并遗留穿插节点。

题目: ​

给你一个长度为 n 的链表，每个节点包含一个额外增加的随机指针 random ，该指针可以指向链表中的任何节点或空节点。

构造这个链表的 深拷贝。 深拷贝应该正好由 n 个 全新 节点组成，其中每个新节点的值都设为其对应的原节点的值。新节点的 next 指针和 random 指针也都应指向复制链表中的新节点，并使原链表和复制链表中的这些指针能够表示相同的链表状态。复制链表中的指针都不应指向原链表中的节点 。

例如，如果原链表中有 X 和 Y 两个节点，其中 X.random --> Y 。那么在复制链表中对应的两个节点 x 和 y ，同样有 x.random --> y 。

返回复制链表的头节点。

用一个由 n 个节点组成的链表来表示输入/输出中的链表。每个节点用一个 [val, random_index] 表示：

  • val：一个表示 Node.val 的整数。
  • random_index：随机指针指向的节点索引（范围从 0 到 n-1）；如果不指向任何节点，则为  null 。

你的代码 只 接受原链表的头节点 head 作为传入参数。

示例 1：

**输入：**head = [7,null],[13,0],[11,4],[10,2],[1,0] 输出：[7,null],[13,0],[11,4],[10,2],[1,0]

示例 2：

**输入：**head = [1,1],[2,1] 输出：[1,1],[2,1]

示例 3：

**输入：**head = [3,null],[3,0],[3,null] 输出：[3,null],[3,0],[3,null]

提示：

  • 0 <= n <= 1000
  • -10^4 <= Node.val <= 10^4
  • Node.random 为 null 或指向链表中的节点。

链表穿插复制 + 拆分链表 ​

解题思路 ​

复制带有 random 指针的链表，难点在于：

  • next 指针可以直接复制。
  • random 指针可能指向任意节点，无法直接确定对应关系。

核心思想：

利用原链表节点和复制节点的位置关系建立映射。

整体分为三步：

  1. 复制节点并插入原节点后面。
  2. 利用相邻关系复制 random 指针。
  3. 拆分链表，得到新的复制链表。

关键思想 ​

1. 复制节点并插入 ​

原链表：

A → B → C

复制后：

A → A' → B → B' → C → C'

让复制节点紧跟原节点，这样可以通过原节点快速找到复制节点。

例如：

A.random = C

那么：

A'.random = C'

可以通过：

python
cur.random.next

找到对应复制节点。

2. 复制 random 指针 ​

遍历原链表：

如果当前节点存在 random：

python
cur.next.random = cur.random.next

其中：

  • cur.next 是复制节点。
  • cur.random.next 是 random 指向节点的复制节点。

3. 拆分链表 ​

复制完成后：

A → A' → B → B' → C → C'

拆分为：

原链表：

A → B → C

复制链表：

A' → B' → C'

算法流程 ​

  1. 遍历链表：

    • 创建复制节点。
    • 插入原节点后面。

  2. 再次遍历：

    • 设置复制节点的 random。

  3. 再次遍历：

    • 分离原链表和复制链表。

  4. 返回复制链表头节点。

复杂度分析 ​

  • 时间复杂度：O(n)

    三次遍历链表。

  • 空间复杂度：O(1)

    没有使用额外哈希表，利用链表结构完成映射。

Python代码 ​

python
class Solution:
    def copyRandomList(self, head: 'Optional[Node]') -> 'Optional[Node]':

        # 第一步：复制节点并插入原链表

        cur = head

        while cur:
            cur.next = Node(cur.val, cur.next)
            cur = cur.next.next


        # 第二步：复制 random 指针

        cur = head

        while cur:

            if cur.random:
                cur.next.random = cur.random.next

            cur = cur.next.next


        # 第三步：拆分链表

        copy_head = head.next if head else None
        cur = head

        while cur:
            clone = cur.next
            cur.next = clone.next
            clone.next = cur.next.next if cur.next else None
            cur = cur.next

        return copy_head

易错点 ​

  1. 插入复制节点的位置：

必须保证：

原节点 → 复制节点

否则无法通过位置关系找到对应节点。

  1. 设置 random 时：

错误：

python
cur.random

因为这是原节点。

正确：

python
cur.random.next

这是对应复制节点。

  1. 拆分链表时注意不要破坏后续连接。

总结 ​

复制复杂链表的核心套路：

复制节点插入
        ↓
利用相邻关系复制 random
        ↓
拆分链表

相比哈希表方法：

方法时间复杂度空间复杂度
哈希表映射O(n)O(n)
链表穿插复制O(n)O(1)

核心思想：

利用链表自身结构建立节点映射，减少额外空间。

哈希表映射复制复杂链表 ​

解题思路 ​

复制带有 random 指针的链表，核心问题是：

普通链表复制只需要复制 next 指针，但是 random 指针可以指向链表中任意节点，因此无法直接确定复制节点应该指向哪里。

解决方法：

使用哈希表建立「原节点 → 新节点」的映射关系。

分两步：

  1. 创建所有复制节点，并建立映射。
  2. 根据映射关系设置 next 和 random 指针。

关键思想 ​

使用哈希表保存：

python
{
    原节点: 复制节点
}

例如：

原链表：

A → B → C

第一次遍历创建：

A → A'
B → B'
C → C'

哈希表：

map[A] = A'
map[B] = B'
map[C] = C'

之后：

如果：

A.random = C

那么：

复制节点：

A'.random = map[C]

即可找到对应节点。

算法流程 ​

第一步：复制节点 ​

遍历原链表：

  • 创建对应的新节点。
  • 存入哈希表。

代码：

python
copy[cur] = Node(cur.val)

第二步：连接指针 ​

再次遍历原链表：

设置：

python
copy[cur].next = copy[cur.next]

copy[cur].random = copy[cur.random]

通过哈希表直接找到对应复制节点。

复杂度分析 ​

  • 时间复杂度：O(n)

    两次遍历链表。

  • 空间复杂度：O(n)

    哈希表存储所有节点映射。

Python代码 ​

python
class Solution:
    def copyRandomList(self, head: 'Optional[Node]') -> 'Optional[Node]':

        if not head:
            return None

        # 原节点 -> 复制节点
        copy = {}

        cur = head

        # 第一次遍历：创建所有节点
        while cur:
            copy[cur] = Node(cur.val)
            cur = cur.next


        cur = head

        # 第二次遍历：连接 next 和 random
        while cur:

            copy[cur].next = copy.get(cur.next)

            copy[cur].random = copy.get(cur.random)

            cur = cur.next


        return copy[head]

易错点 ​

  1. 哈希表存储的是：
原节点对象 → 新节点对象

不是：

节点值 → 新节点

因为不同节点可能有相同的值。

  1. 设置指针时需要使用：
python
copy[cur.next]

而不是：

python
cur.next

因为需要连接的是复制链表。

  1. 空节点处理：

例如：

python
cur.random = None

此时：

python
copy.get(None)

返回：

python
None

避免额外判断。

总结 ​

复制复杂链表有两种经典方法：

方法核心思想时间复杂度空间复杂度
哈希表映射保存原节点和复制节点对应关系O(n)O(n)
链表穿插复制利用节点相邻位置建立映射O(n)O(1)

哈希表方法：

第一次遍历：创建节点并建立映射

第二次遍历：根据映射连接指针

优点：

  • 思路简单。
  • 容易理解。
  • 适合面试快速写出。

缺点：

  • 需要额外 O(n) 空间。
