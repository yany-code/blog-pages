滑动窗口最大值：单调队列为什么只保留候选者 ​

窗口每向右移动一步，都要得到新的最大值。困难在于：旧最大值离开以后，谁来接替它？单调队列给出的办法，是提前保留可能接替的候选者，并及时删除以后再也用不上的元素。

题意与重复计算 ​

LeetCode 239：滑动窗口最大值 给定数组和窗口长度 k，要求按窗口从左到右的顺序返回每个最大值。题目保证 1 <= k <= nums.length。

每次重新扫描窗口，需要 O(nk) 时间。若只记住一个最大值，它一旦过期，又得重新查找。需要维护的是一个能随窗口更新的候选集合。

为什么可以删掉队尾 ​

假设旧下标为 j，新下标为 i，且 j < i、nums[j] <= nums[i]。以后任何仍然包含 j 的窗口，只要它的右边界不小于 i，就也包含 i。

新元素数值不小于旧元素，而且离开窗口的时间更晚。旧元素从此不可能单独成为窗口最大值，因此可以删除。这个删除依据是“未来已经没有竞争力”，而不是“当前不是最大值”。

相反，较小的新元素需要保留：前面的较大元素过期以后，它仍有可能接替最大值。只有新元素支配的队尾可以被移除。

队列维护的两个不变量 ​

队列保存下标，从队头到队尾，下标递增，对应的数组值严格递减。因此队头就是当前窗口最大值的位置。

保存下标使我们可以准确判断过期。右端点为 i 时，窗口左端点是 left = i - k + 1，所有小于 left 的下标都必须从队头删除。随后，从队尾删除值小于等于新值的元素，再将 i 入队。

这里使用 <= 处理重复值：相等时保留更晚到达的下标，因为它能服务更久。使用 < 也能正确求最大值，但会保留多余的相同候选者。

一组输入的队列变化 ​

取 nums = [4, 2, 2, 5, 1]，k = 3。表中使用“下标:值”表示队列元素。

右端点 i清理并入队后的队列当前窗口最大值
0[0:4]窗口未满
1[0:4, 1:2]窗口未满
2[0:4, 2:2]4
3[3:5]5
4[3:5, 4:1]5

i = 2 时，新出现的 2 替代旧的 2。i = 3 时，下标 0 已经过期，剩余的 2 又被新值 5 淘汰，答案最终为 [4, 5, 5]。

Java 实现 ​

java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public int[] maxSlidingWindow(int[] nums, int k) {
        int[] answer = new int[nums.length - k + 1];
        Deque<Integer> queue = new ArrayDeque<>();

        for (int i = 0; i < nums.length; i++) {
            int left = i - k + 1;

            // 先移除已经不在窗口中的下标。
            while (!queue.isEmpty() && queue.peekFirst() < left) {
                queue.removeFirst();
            }

            // 新元素更大或相等，并且更晚过期。
            while (!queue.isEmpty()
                    && nums[queue.peekLast()] <= nums[i]) {
                queue.removeLast();
            }
            queue.addLast(i);

            if (left >= 0) {
                answer[left] = nums[queue.peekFirst()];
            }
        }
        return answer;
    }
}

复杂度与易错点 ​

虽然有两个 while，每个下标只会入队一次，并且最多被移除一次。把所有循环合在一起计数，总时间为 O(n)。队列只保存窗口内的候选下标，辅助空间为 O(k)，返回数组另占 O(n - k + 1)。

  • 队列存下标，输出时再通过下标取值。
  • left >= 0 才说明第一个完整窗口已经形成。
  • 过期条件是 index < left，左端点自身仍然有效。
  • k = 1 应返回原数组各元素；k = n 只返回一个最大值。
  • 全部元素相等、严格递增和严格递减，分别能检查去重、队尾清理与队头过期。

单调队列的关键是识别“永远不可能再成为答案”的候选者。理解这一点以后，队头负责过期、队尾负责淘汰的分工就自然了。
