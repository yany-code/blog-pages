02 · Prompt 与消息模板 ​

以下保留原学习资料的章节结构与版本语境；示例依赖对应环境，接入真实项目时需按所用版本配置。

迁移校订

  • 已校正模板类名、方法名、变量名和 YAML 围栏；这些示例分段展示接口，model、消息类及依赖仍需先初始化或导入。外置提示词加载 API 需按所安装的 LangChain 版本核对。

1、核心认知: ​

  • Prompt的工程化演进过程: 随手写的纯字符串 --> 多角色消息列表(System/User/AI) --> 模块化(提取变量) --> 动态消息占位符 --> JSON/YAML 文件外置配置
  • 核心原则: 稳定约束和动态输入必须拆开写。系统规则放SystemMessage, 当前任务/变量放 HumanMessage

2、消息体系: ​

2.1、四大核心消息角色: ​

消息类名对应原生 API 角色核心职责工程典型场景
SystemMessagesystem设定人设、规则边界、输出约束“你是法律顾问”、“只回答50字内”、“禁止推测”
HumanMessageuser承载用户的当前输入/提问聊天框输入、动态业务问题
AIMessageassistant记录大模型的历史回复存入多轮对话上下文、提供历史参考
ToolMessagetool承载外部工具/函数执行的结果Agent 查数据库、调天气接口后返回的原始数据

2.1、三种等价输入语法 ​

python
# 语法 1：面向对象写法（最严谨、最显式，推荐教学与复杂系统）
messages = [
    SystemMessage(content="你是AI助手"),
    HumanMessage(content="你好")
]

# 语法 2：元组列表（最清爽，业务代码中最常见，配合 ChatPromptTemplate 极佳）
messages = [
    ("system", "你是AI助手"),
    ("human", "你好")   # 写 "user" 或 "human" 均可
]

# 语法 3：字典列表（兼容原生 OpenAI JSON 格式）
messages = [
    {"role": "system", "content": "你是AI助手"},
    {"role": "user", "content": "你好"}
]

3、模型调用的 3 大方式 ​

调用方式同步方法异步方法 (async/await)核心特点适合业务场景
单次全量model.invoke(...)model.ainvoke(...)一次发一条，等全部生成完毕返回离线脚本、短问答、后台自动化处理
流式打字model.stream(...)model.astream(...)生成一个词吐一个词（Chunk），大幅降低首字等待Web 聊天窗口、打字机效果、长文本生成
批量并行model.batch(...)model.abatch(...)一次性传输入列表，并发处理多条请求离线批量清洗数据、批量做分类评估

4、文本提示词模板:PromptTemplate ​

针对单端纯文本任务, 不强制区分角色

4.1、创建方式 ​

python
from langchain_core.prompts import PromptTemplate

# 推荐：from_template（自动推断占位符变量）
template = PromptTemplate.from_template("请用不超过 50 字介绍：{topic} 是什么？")

# 传统构造函数方式
template = PromptTemplate(
    template="请用不超过 50 字介绍：{topic} 是什么？",
    input_variables=["topic"]
)

4.2、三大常用方法 ​

  • format(...): 生成纯字符串(str), 最直观:
python
prompt_str = template.format(topic = "LangChain")
  • invoke(...): 生成PromptValue 对象(供 LCEL 管道|传递使用):
python
val = template.invoke({"topic": "LangChain"})
  • partial(...): 局部固定变量(先固定一部分不变的参数, 后续只传动态参数)
python
tpl = PromptTemplate.from_template("{role}, 请解释{topic}")
# 先把角色固定写死, 得到一个新模板
python_tpl = tpl.partial(role = "你是一名资深 Python 架构师")
prompt_str = python_tpl.format(topic = "装饰器")

5、对话提示词模板: ChatPromptTemplate(✨) ​

面向 聊天模型/多轮交互 的模板系统, 填值后得到的是 多条带角色的消息结构。

5.1、推荐写法与参数填充 ​

python
from langchain_core.prompts import ChatPromptTemplate

# 推荐: from_messages 配合元组简写
chat_prompt = ChatPromptTemplate.from_messages([
	("system", "你是一名专攻 {field} 的 AI 专家, 只回答该领域的问题。"),
	("human","请问: {question}")
])

5.2、三种输出方法的区别(必记) ​

python
# 1. format_messages() -> 得到 [SystemMessage, HumanMessage] 列表 (直接给模型)
messages = chat_prompt.format_messages(field = "python", question = "什么是 GIL?")
resp = model.invoke(messages)

# 2. invoke() -> 得到 ChatPromptValue (LCEL 链式语法使用)
prompt_value = chat_prompt.invoke({"field": "python", "question": "什么是 GIL?"})
resp = model.invoke(prompt_value)

# 3. format() -> 得到拼接好的单条字符串 (通常仅用于 print 调试观察)
print(chat_prompt.format(field = "python", question = "什么是 GIL?"))

6、核心武器: MessagesPlaceholder(消息占位符) ​

  • 痛点: 多轮历史对话的轮数是不确定的(有时 2 轮, 有时 10 轮), 模板无法写死{history}。
  • 作用: 在模板中挖一个"消息列表专属的大坑", 运行时把多轮[HumanMessage, AIMessage, ...] 整个列表原封不动塞进去! 代码标准范式:
python
from langchain_core.messages import HumanMessage, AIMessage
from langchain_core.prompts import ChatPromptTemplate, MessagesPlaceholder

prompt = ChatPromptTemplate.from_messages([
	("system","你是公司专属助理"),
	# 挖坑: 占位符名字叫"chat_history"
	MessagesPlaceholder("chat_history"),
	("human", "{question}")
])

# 运行时将历史消息整块塞入
prompt_val = prompt.invoke({
	"chat_history": [
		HumanMessage(content = "我叫小明, 负责前端"),
		AIMessage(content = "收到, 小明!")
	],
	"question": "我刚才说我是负责什么的?"
})

7、工程化进阶: 从外部文件(JSON / YAML)加载 Prompt ​

避免将又臭又长的提示词硬编码在Python代码中, 便于**版本控制、A/B测试、**非开发人员(运营/产品)协同修改。 [ 1 ] prompt.yaml(推荐, 可读性好, 支持注解):

yaml
_type: "prompt"
input_variables:
  - "role"
  - "question"
template: "你是一个专业的{role}，请简明回答：{question}"

[ 2 ] Python 代码加载:

python
from pathlib import Path
from langchain_core.prompts import load_prompt

# 建议基于脚本当前绝对路径定位, 避免因执行目录不同导致找不到文件
prompt_path = Path(__file__).resolve().with_name("prompt.yaml")
template = load_prompt(prompt_path, encoding = "utf-8")

prompt_str = template.format(role = "DBA", question = "什么是索引覆盖?")

💡 核心考点与背诵口诀 ​

  1. 单文本 vs 多角色：
    • 做纯文本补全/单句填空，用 PromptTemplate；
    • 做聊天/助手/Agent，必用 ChatPromptTemplate。
  2. 历史记忆怎么插：
    • 千万不要手动拼接字符串！在模板里放 MessagesPlaceholder("history")，运行时传消息对象列表。
  3. 固定参数怎么省：
    • 常用公共参数用 .partial() 先固定，后续调用只传动态变化参数。
  4. 输出方法选哪个：
    • 只要传给模型，用 format_messages() 或 invoke()；只有排查打印看字时，才用 format()。
