04 · LCEL 与链式调用 ​

以下保留原学习资料的章节结构与版本语境；示例依赖对应环境，接入真实项目时需按所用版本配置。

1、核心底座: Runnable(可执行组件协议) ​

1.1、什么是Runnable? ​

  • 定义: Runnable 是 LangChain 内部最核心的抽象协议/接口。
  • 核心思想: 无论是Prompt（模板）、Model（模型）、Parser（解析器）、Tool（工具）、甚至整条 Chain（链）, 都被抽象为同一个角色——"可执行的数据处理节点(Runnable)"。
  • 带来的最大好处: 所有组件对外的方法完全一致, 像搭积木一样即插即用!

2.2、Runnable家族的 6 大标准调用方法（必记） ​

所有实现了 Runnable 协议的对象，天然具备以下统一接口:

调用维度同步方法异步方法 (async/await)核心用途
单次执行.invoke(input).ainvoke(input)处理单条输入（最常用）
流式打字.stream(input).astream(input)边生成边吐出 Chunk（聊天窗口打字机）
批量并行.batch([inputs]).abatch([inputs])一次性传输入列表，多线程/协程并发加速

2、什么是LCEL?（不只是语法糖） ​

  • 定义: LCEL(LangChain Expression Language) 是用声明式语法把多个 Runnable 组件连接起来的表达式语言。
  • 标志性写法: |(管道符)
python
# 最经典的 Model I/O 三段式流水线
chain = prompt | model | StrOutParser()
  • LCEL 的三大硬核价值:
    1. 自动数据流转: 自动把前一步的输出, 作为后一步的输入, 省去大量手写临时变量。
    2. 能力自动继承: 两个 Runnable 用 | 拼成 Chain 之后, 这条 Chain 本身依然是一个 Runnable, 它自动继承 invoke、stream、batch 等所有能力。
    3. 生产级扩展: 可以非常方便地在链上直接挂在重试(.with_retry)与兜底(/with_fallbacks)。

3、LCEL 的 5 种核心链式结构（代码范式） ​

3.1、顺序链（RunnableSequence）——最基础主干 ​

  • 特点: 单线推进, A的输出给B, B的输出给C。
python
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser

prompt = ChatPromptTemplate.from_template("讲一个关于 {topic} 的冷笑话")
# 底层等价于：RunnableSequence(first=prompt, middle=[model], last=StrOutputParser())
chain = prompt | model | StrOutputParser()

# 调用：整条链直接像普通组件一样 invoke
result = chain.invoke({"topic": "程序员"})

3.2、分支链（RunnableBranch）——意图路由/if-else ​

  • 特点: 根据输入条件, 动态选择走那条分支链, 有默认兜底链。
python
from langchain_core.runnables import RunnableBranch

# 语法：RunnableBranch((条件1, 链1), (条件2, 链2), 默认链)
branch = RunnableBranch(
    (lambda x: "代码" in x["query"], code_chain),
    (lambda x: "翻译" in x["query"], translate_chain),
    chat_chain # 默认兜底
)

3.3、并行链（RunnableParallel）——多路齐发 ​

  • 特点: 同一份输入, 同时喂给多个子链执行, 最后汇总成一个 dict。
  • 经典写法: 直接用 Python 字典 包装即可!
python
from langchain_core.runnables import RunnableParallel

# 场景：同时生成中文和英文摘要
parallel_chain = {
    "chinese_summary": prompt_zh | model | StrOutputParser(),
    "english_summary": prompt_en | model | StrOutputParser(),
}

# 调用后直接得到字典结果：{"chinese_summary": "...", "english_summary": "..."}
result = parallel_chain.invoke({"article": "长文内容..."})

3.4、函数链/胶水层（RunnableLambda）——自定义清晰与映射 ​

  • 特点: 前后节点的入参/出餐格式对不上时, 把普通 Python 函数变成 Runnable 节点充当"转接头"。
python
from langchain_core.runnables import RunnableLambda

def format_input(text: str) -> dict:
    # 把上一步出来的纯字符串，包装成下一步 Prompt 需要的字典
    return {"query": text.strip()}

# 两种写法等价（推荐直接把函数名放进管道符）：
chain = step1_chain | format_input | step2_chain
# 或显式包装：step1_chain | RunnableLambda(format_input) | step2_chain

3.5、多步串行链（Multi_Step Chain） ​

  • 特点: 多阶段加工。比如: 【输入主题】 -> 节点1（写大纲） -> 结构转换 -> 节点2（扩写文章） -> 输出。
python
outline_chain = prompt1 | model | StrOutputParser()
article_chain = prompt2 | model | StrOutputParser()

# 中间用 lambda 连接上下两步
full_chain = (
    outline_chain
    | (lambda outline: {"outline": outline})
    | article_chain
)

4、生产级稳定性: 重试与兜底 ​

真实项目中模型会遇到偶尔超市、报错、LCEL 提供了原生的防护机制

python
# 1. 失败自动重试（防网络临时抖动）
reliable_chain = chain.with_retry(stop_after_attempt=3)

# 2. 备用模型兜底（主模型挂了自动切备用模型）
robust_chain = primary_chain.with_fallbacks([backup_chain])

5、进阶技巧: 可视化你的 LCEL 链 ​

在终端里可以直接用 ASCII 字符打印整条链的拓扑图, 为后续学习 LangGraph 打下图论思维的基础:

python
# 打印链的结构图（需安装 grandalf 库）
chain.get_graph().print_ascii()

💡 核心考点与背诵口诀 ​

  1. 统一抽象叫 Runnable：所有组件同协议，单次 invoke 批量 batch，前端打字走 stream。
  2. 管道连接叫 LCEL：prompt | model | parser 三位一体，输出即输入，组合出来的还是 Runnable。
  3. 分流路由用 Branch：类似 if-elif-else，意图分流必备。
  4. 并发处理用 Parallel：直接写字典 { "k1": chain1, "k2": chain2 }，多路并行算完汇合成 dict。
  5. 格式对不上用 Lambda：普通 Python 函数塞进管道，充当胶水转接头。
