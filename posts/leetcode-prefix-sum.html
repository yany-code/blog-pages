和为 K 的子数组：用前缀和统计历史状态 ​

这道题让我注意到，哈希表除了回答“有没有”，还可以回答“此前出现过多少次”。把连续区间换成两个历史状态之差，原本需要枚举起点的问题，就只剩一次查询。

题意与最直接的做法 ​

LeetCode 560：和为 K 的子数组 要求统计整数数组中，元素之和等于 k 的连续、非空区间数量。

最直接的方法是固定起点，再向右累加，每遇到一次目标和就计数。这样有 O(n²) 个候选区间。数组允许负数，扩大窗口时总和可能减小，缩小窗口时也可能增大，因此不能靠“和太大就移动左边界”稳定地排除答案。

把区间和变成历史查询 ​

令 prefix[j] 表示前 j 个元素的总和，特别地 prefix[0] = 0。左闭右开的区间 [i, j) 满足：

text
区间和 = prefix[j] - prefix[i]
区间和等于 k ⇔ prefix[i] = prefix[j] - k

扫描到右端点 j 时，当前前缀和已经确定。只要知道以前有多少个前缀和等于 prefix[j] - k，就知道以当前位置结尾的合法区间有多少个。

这里必须保存次数。不同位置可能得到相同前缀和，它们对应不同起点，不能用集合去重。哈希表的键是前缀和，值是它在历史位置出现的次数。

不变量与更新顺序 ​

每轮查询之前，count 只包含当前元素之前的前缀和。初始化 count[0] = 1，表示数组开始前的空前缀，它让从下标 0 开始的合法区间也能被统计。

每加入一个元素，严格按三个步骤更新：

  1. 累加元素，得到新的 sum。
  2. 把 count[sum - k] 加入答案。
  3. 将当前 sum 的出现次数加一，供后续位置使用。

查询必须发生在记录当前状态之前。当 k = 0 时，如果先记录，就会把当前前缀与自身配对，错误地算入长度为零的区间。

用一组含负数的输入走一遍 ​

取 nums = [1, -1, 1]，k = 1。初始只有 count = {0: 1}。

加入的元素当前 sum需要的历史和新增区间数累计答案
11011
-10-101
11023

最后一次查询时，前缀和 0 已出现两次，分别对应整个 [1, -1, 1] 和末尾的 [1]。再加上开头的 [1]，答案为 3。

Java 实现 ​

java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int subarraySum(int[] nums, int k) {
        Map<Integer, Integer> count = new HashMap<>();
        count.put(0, 1);

        int sum = 0;
        int answer = 0;
        for (int x : nums) {
            sum += x;
            answer += count.getOrDefault(sum - k, 0);
            count.put(sum, count.getOrDefault(sum, 0) + 1);
        }
        return answer;
    }
}

复杂度与易错点 ​

哈希查询和更新的平均成本为 O(1)，总时间为平均 O(n)，不同前缀和最多 n + 1 个，空间为 O(n)。在本题给定的数组长度与元素范围内，前缀和和答案都可用 Java int 保存；迁移到更大数据范围时，应重新检查是否需要 long。

  • 初始的 0: 1 表示空前缀，不是空子数组。
  • 同一个前缀和需要累计次数，不能覆盖成 1。
  • 先查历史，再记录当前，保证区间非空。
  • [0, 0]、k = 0 应得到 3，很适合检查上述顺序。

这次练习中最值得留下的是“按右端点计数”的视角：当前状态只负责查询，与所有历史起点的配对工作交给哈希表。
