Python 语法学习计划（面向 C++/Java 程序员） ​

目标：掌握 Python 语言核心，达到能自主学习 LangChain / 数据分析（NumPy、Pandas）/ 机器学习 / 深度学习 的程度。 基础假设：你已具备变量、循环、函数、面向对象、异常处理等通用编程概念。 策略：不讲"什么是循环"，只讲 Python 怎么写循环、和 C++/Java 差在哪、地道写法是什么。

二、C++/Java → Python 差异速查表 ​

先建立整体印象，各章会逐一展开：

概念C++ / JavaPython

常量const / final无真正常量，全大写命名约定 MAX_SIZE = 100

第 1 章 环境搭建与运行方式（1.5h）⭐⭐ ​
  • [x] 本章完成

学习内容

  • 安装 Python、验证版本：python --version
  • 三种运行方式：交互式 REPL、python xxx.py、IDE（推荐 VS Code + Python 插件 或 PyCharm）
  • 注释：# 单行，"""docstring""" 文档字符串
  • 包管理入门：pip install numpy、pip list

与 C++/Java 对照

  • 没有编译链接环节，.py 源码直接解释执行（实际会编译成 .pyc 字节码）
  • venv ≈ 轻量版的 Maven/Gradle 项目隔离 + 没有"全局 jar 包地狱"的解法

练习

  1. 安装环境，写 hello.py，三种方式各运行一次
  2. 创建并激活一个 venv，pip install 一个库再卸载

通关标准：能独立创建 venv、安装第三方库、运行脚本。

第 2 章 变量、动态类型与基础类型（2h）⭐⭐⭐ ​
  • [x] 本章完成

学习内容

  • 变量无需声明类型：x = 10，x = "abc" 合法——理解名字绑定对象
  • 基础类型：int（无限精度！）、float、bool（True/False 首字母大写）、str、None
  • 类型查看与转换：type()、isinstance()、int()、str()、float()
  • 运算符：// 整除、** 幂、链式比较 1 < x < 10、逻辑运算用英文 and/or/not
  • f-string 格式化（重点）：f"{x:.2f}"、f"{name=}"、对齐与千分位
  • 可变性初步：int/float/str/bool/tuple 不可变；重新赋值 = 换绑对象

与 C++/Java 对照

  • int 没有溢出，任意精度；float 即 double
  • 一切皆对象，10 也是对象，10 .bit_length() 合法

练习

  1. 写程序演示 7/2、7//2、-7//2（向下取整，和 C++ 不同！）
  2. 用 f-string 输出格式化表格（对齐、保留小数、百分比）

通关标准：能解释"变量是名字不是盒子"，熟练使用 f-string。

第 3 章 流程控制（2h）⭐⭐⭐ ​
  • [x] 本章完成

学习内容

  • if / elif / else，注意冒号与缩进，无括号
  • 三元表达式：y = "偶" if x % 2 == 0 else "奇"
  • while、while...else（少用，知道即可）
  • for x in 可迭代对象：Python 只有这种 for
  • range(start, stop, step)、enumerate()（同时拿下标和值）、zip()（并行遍历）
  • break / continue
  • match...case 结构化匹配（3.10+，类似 switch 但更强大）

与 C++/Java 对照

  • 没有 do...while；没有 switch（用 match 或字典替代）
  • 遍历列表时用 for x in lst 而不是 for i in range(len(lst))——这是最常见的新手坏味道

练习

  1. 用 for + enumerate + zip 重写三个你熟悉的 Java 风格循环
  2. 用 match 写一个简单计算器分发逻辑

通关标准：写循环时下意识用 for x in 和 enumerate，而不是 range(len(...))。

第 4 章 四大内置容器（4h）⭐⭐⭐ 学习重心！ ​
  • [x] 本章完成

学习内容

  • list：增删改查 append/insert/pop/remove/del、排序 sorted/list.sort(key=, reverse=)、in 成员判断、拼接、* 重复
  • 切片（重点）：lst[1:5]、lst[::-1]、lst[:3]、步长切片
  • tuple：不可变序列、解包 a, b = (1, 2)、交换变量 a, b = b, a、函数多返回值的本质
  • dict：get(key, default)、setdefault、keys/values/items、合并 {**d1, **d2}、3.7+ 保持插入序
  • set：去重、交并差 & | - ^
  • 可变 vs 不可变（本阶段最重要概念）：
    • 默认参数陷阱：def f(x, lst=[]) 为什么危险
    • 深浅拷贝：copy.copy() vs copy.deepcopy()，b = a 只是引用别名
  • 解包与多变量赋值：first, *rest = lst

与 C++/Java 对照

  • list ≈ ArrayList，dict ≈ HashMap<Object,Object>（key 可用任意不可变类型），set ≈ HashSet
  • tuple 是 C++ std::tuple 的日常化，Python 里用得非常多
  • 下标越界：越界读抛 IndexError（不像 C++ 是未定义行为）；支持负下标 lst[-1] 是最后一个

练习

  1. 用 dict 统计一段文本中每个单词出现次数（后面会和 Counter 对比）
  2. 写代码演示：a = [1,2]; b = a; b.append(3) 之后 a 是什么？如何真正复制？
  3. 实现函数 min_max(lst) 返回 (最小值, 最大值) 元组，调用方解包接收

通关标准：能准确判断任意赋值/传参场景下是引用还是拷贝；切片与解包信手拈来。这是后面 NumPy/Pandas 的直接基础。

第 5 章 推导式与迭代协议入门（2h）⭐⭐⭐ Python 之魂 ​
  • [x] 本章完成

学习内容

  • 列表推导式：[x**2 for x in lst if x > 0] —— 替代 Java 的 Stream.map/filter
  • 带 if-else 的推导式：[x if x > 0 else -x for x in lst]
  • 字典推导式、集合推导式
  • 生成器表达式：(x**2 for x in lst) —— 惰性求值，不占内存
  • 什么时候用推导式 vs 普通 for（超过一层嵌套/逻辑复杂时就用 for）
  • 什么可被 for 遍历？可迭代协议初识：iter() 与 next()

与 C++/Java 对照

  • ≈ Java Stream API 的 stream().filter().map().collect()，但更简洁且是语言级语法

练习

  1. 用一行推导式：把 ["a.txt", "b.md", ...] 中所有 .md 文件名转大写
  2. 把一个 dict 反转（value 作 key）
  3. 用生成器表达式处理"100 万个数"而不爆内存，对比列表写法的内存差异

通关标准：看到简单 for+append 循环能立刻改写成推导式。

第 6 章 函数（3h）⭐⭐⭐ ​
  • [x] 本章完成

学习内容

  • def 定义、return 可返回多个值（元组解包）
  • 参数体系（重点）：位置参数、关键字参数、默认参数、*args（可变位置）、**kwargs（可变关键字）、仅限关键字参数 def f(a, *, b)
  • 默认参数陷阱回顾：可变默认值 def f(x, lst=[])
  • 作用域 LEGB：Local → Enclosing → Global → Built-in；global / nonlocal
  • 函数是"一等公民"：函数可以赋值给变量、当参数、当返回值（为装饰器铺路）
  • lambda 匿名函数：sorted(lst, key=lambda x: x[1])
  • 类型注解入门：def add(a: int, b: int) -> int:（运行时不强制，但 IDE/文档价值巨大）
  • 文档字符串 docstring 规范

与 C++/Java 对照

  • 没有重载 → 一个函数 + 默认参数/关键字参数解决
  • 没有 static 方法一说，函数本身就是对象

练习

  1. 写 def create_counter(): 返回一个内部函数，每次调用计数 +1（体会闭包雏形）
  2. 写 def sum_all(*args, **kwargs) 演示两类打包参数
  3. 用 sorted + lambda 按多个字段排序 [(姓名, 年龄, 分数)] 列表

通关标准：能设计出参数友好的函数签名；理解函数可以作为值传递。

第 8 章 面向对象——Python 风格（4h）⭐⭐⭐ ​
  • [ ] 本章完成

学习内容

  • class 定义、__init__ 构造、self 的本质（就是显式的 this）
  • 实例属性 vs 类属性
  • 方法类型：实例方法、@classmethod（常作替代构造器）、@staticmethod
  • 继承与 MRO：class Child(Parent)、super().__init__()、多继承与方法解析顺序（C3 线性化）
  • 鸭子类型：不看类型看行为 —— Python 的"接口"哲学
  • 抽象基类 abc.ABC + @abstractmethod（需要强制接口时才用）
  • dunder（魔法）方法（重点）：__str__ / __repr__ / __eq__ / __len__ / __getitem__ / __call__ —— 让自定义对象支持 print、==、len()、[]、for 遍历
  • @property：把方法伪装成属性（替代 getter/setter）
  • 私有约定：_name、__name
  • @dataclass：一行生成 __init__/__repr__/__eq__（写 LangChain/pydantic 前必会）

与 C++/Java 对照

  • 无访问修饰符，全靠约定；无接口关键字，默认鸭子类型
  • 无方法重载；运算符可重载（同 C++），通过 dunder 方法
  • 多继承合法（Java 单继承+接口），需理解 MRO 避免坑

练习

  1. 写一个 Vector 类：支持 +、*、==、len()、print、下标访问
  2. 用 @dataclass 重写一个 Student(name, age, scores)，含平均分 @property
  3. 写 Animal → Dog/Cat 继承结构，演示多态（无需共同父类也行的鸭子类型版本）

通关标准：读懂 LangChain 中 class XxxChain(BaseChain): 这类代码不吃力；能自定义 dunder 方法。

第 13 章 闭包与装饰器（3h）⭐⭐⭐ Python 精髓 ​

  • 闭包：内层函数记住外层变量（第 6 章 create_counter 回顾加深）
  • 装饰器：@decorator 语法 = func = decorator(func)
  • 手写一个装饰器：计时器、日志器
  • functools.wraps 保留原函数元信息
  • 带参数的装饰器（三层嵌套）
  • 类装饰器（了解）、多处叠加装饰器的执行顺序
  • 为什么必须学：@property、@staticmethod、@dataclass、@cache、LangChain 的 @tool、Web 框架路由 @app.route —— 全是装饰器

与 C++/Java 对照

  • ≈ Java 注解 + AOP 的合体，但是语言原生、直接改写函数对象；C++ 需模板/宏模拟

练习

  1. 写 @timeit 装饰器，统计任意函数耗时
  2. 写带参数的 @retry(times=3)：失败自动重试
  3. 写 @cache 版斐波那契，对比性能（可用 functools.cache 验证正确性）

通关标准：能手写无参/带参装饰器；见到 @xxx 知道它是"包了一层的函数"。

  • datetime：日期时间、timedelta、格式化 strftime/strptime

  • re 正则表达式：match / search / findall / sub，常用模式（你有 C++/Java 正则基础，重点看 Python 语法差异 raw string r"\d+"）

  • os / sys / random / math / time：速览

第 16 章 异步编程 asyncio（3h）⭐⭐（LangChain 重要基础） ​
  • [ ] 本章完成

学习内容

  • 为什么需要异步：IO 密集场景（调 LLM API、爬虫、Web 服务）
  • async def 协程函数、await、事件循环 asyncio.run()
  • 并发执行：asyncio.gather()、create_task
  • 异步上下文管理器 async with、异步迭代器/异步生成器 async for + yield（LangChain 流式输出的直接基础！）
  • 同步 vs 异步的心智模型：单线程内"等待时切换任务"

与 C++/Java 对照

  • ≈ Java 的 CompletableFuture / 虚拟线程目标，但语法级集成（类似 JS 的 async/await）

练习

  1. 顺序 await 三个模拟耗时任务 vs gather 并发，对比总耗时
  2. 写一个异步生成器，模拟"逐词产出 AI 回答"并用 async for 消费

通关标准：能写简单的 async 并发程序，看懂 async for 流式消费代码。
